# Provider activation
For QuickBooks Online, Stripe, Shopify, UPS, ADP Workforce Now, Salesforce Sales Cloud, and Microsoft Teams: register separate staging and production OAuth apps; store only Key Vault references; validate redirect URIs, refresh/revocation, webhook signatures, duplicate delivery, rate limits, reconciliation, and tenant-specific activation. Advance one level at a time: disabled, read-only, reversible write, draft accounting, logistics, workforce draft, high-risk. Never infer success from a timeout; mark uncertain, lock retries behind idempotency, and reconcile with the provider.
